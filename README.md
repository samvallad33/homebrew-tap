# homebrew-tap

Homebrew tap for Vestige, the local-first memory system for AI coding agents.

    brew install samvallad33/tap/vestige

Vestige ships as a single Rust binary set: vestige-mcp is the MCP server, vestige is the CLI with the backfill and composed-graph commands, vestige-restore recovers a store. Releases and source live at github.com/samvallad33/vestige. AGPL-3.0.
